# Bootstrap the first poster

Follow [COD-67](https://linear.app/codekips/issue/COD-67) and the
[Odyssey tracer-bullet plan](exec-plans/active/odyssey-tracer-bullet.md).

Use Go modules, the standard library, and `golang.org/x/image`. Retain the Odyssey
text, obtain an approved transparent master with the existing skill, and build the smallest
conversion/render/display path. Put the actual setup and run commands in README
as they are implemented.

Choose practical defaults in the first pass and adjust them from the displayed
poster. Keep a small offline mapping fixture and record a real rendered proof;
do not require separate specification, environment, validation, conversion,
rendering, and CI projects before producing that proof.

Once the first poster works, continue with the curation web app, then one Printful
poster, then an optional mug. Keep store and sales work outside this scope.
Remove this bootstrap guide and its links when the first journey is established.
